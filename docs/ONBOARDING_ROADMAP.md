# Account onboarding

Public practice: `/try` has no wallet, account, charges or private writes. The sample dashboard is synthetic. The separate `/proof` set contains 30 genuine confirmed Mainnet records and dated measured recall.

Individual workspace: `/connect` uses Sui Wallet Standard discovery, a displayed personal-message challenge and backend verification. A returning verified wallet opens the same isolated Neon profile. A new profile begins empty. Seven workspace milestones link to supplier creation, established reference, invoice intake, changed-recipient review, independent human check, consensual memory correction, and later recall. Completion indicators derive from saved records and do not claim to prove a fresh-session test by themselves.

Administrator: Owner Sign In is a separate password-protected identity. Seed/reset, integration diagnostics and the controlled Testnet service-payment pilot remain administrator-only. Wallet accounts do not inherit these permissions.

Future work: team workspaces and reviewer roles, account recovery/export/deletion, independent security audit, certified mobile wallet matrix, optional delegated per-user memory credentials. Operator-managed storage and retention limitations are disclosed at `/privacy`. No supplier-payment execution is planned in this MVP.

PayGuard AI
The payment guardian that remembers.
PayGuard AI is an adaptive invoice and payment-review agent built for the Total Recall: Tatum × Walrus hackathon (Track 02 — Smart Agents for Real Life).
Most payment tools remember transactions. PayGuard remembers why a transaction was approved, questioned or rejected. It reviews invoices, explains inconsistencies, monitors read-only Sui wallet activity, verifies payment evidence using Tatum, and learns from user corrections via Walrus Memory on Mainnet.
Core experience
Review manually entered and text-based PDF invoices, with editable extracted fields.
Detect possible duplicates, unexpected recipient changes and unusual amounts.
Teach PayGuard merchant-specific approval rules through explicit corrections.
Recall learning across sessions using Walrus Memory, with observable Memory ON/OFF comparisons.
Watch Sui addresses and inspect transaction proofs through Tatum Sui RPC.
Keep a transparent review and audit history; users retain final payment decisions.
Technology
